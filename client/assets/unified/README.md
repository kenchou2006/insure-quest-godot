# 統一美術風格

採用第二十五版素材包的電影感寫實人物、深翡翠綠、暖金光與台北夜景。

- `background.webp`：封面背景圖層，主選單與全域背景。
- `board.webp`：乾淨無格子的台北生活圈地圖，棋盤中央。
- `coach.webp`：女性顧問立繪，結算教練。
- `portraits/<id>.webp`：18 位固定客戶頭像，保留原客戶 ID 對應。
- `portraits/pool_*.webp`：動態客戶的共用頭像；優先採用同齡素材，50／60 歲女性由 ImageGen 補齊。

18 張 `../clients/` 訪談場景經 SHA-256 比對與素材包一致，因此保留原場景與線索座標。五張 `../howto/` 圖片使用素材包的規則教學配圖。啟動封面使用 `../startup/loading.png` 背景、`advisor_f.png`／`advisor_m.png` 顧問立繪與 `title.png`「人生顧問局」透明標題圖層。

補圖提示：單人方形胸像、台灣女性、分別為 50 多歲與 60 多歲、自然符合年齡的肌膚與髮色、友善表情；電影感寫實、翡翠綠城市背景、細金色幾何裝飾、暖金輪廓光與藍綠夜景；無文字、無浮水印、無介面。以完整封面為風格參考，使用內建 ImageGen。

舊版圖片保留以便還原，但執行時優先載入本資料夾。

載入中使用 `../startup/loading.png`（無按鈕的夜景背景），進度條結束後才顯示帶有進入按鈕的完整封面。
