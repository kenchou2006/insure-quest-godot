# INSURE QUEST 人生顧問局 (Life Advisor Bureau) (Godot Web Edition)

BNP Paribas Cardif InsurHack Topic 1-1 "Insurance Monopoly": A multiplayer web game using Monopoly mechanics to train insurance advisors on "needs-based selling and compliance communication".
Supports 2–4 players online, solo practice against bot advisors, AI clients, and AI coach; installable as a PWA.

## Architecture: One Worker, Single Deployment

```
Browser (Godot Web / PWA)
   │  Same domain
   ▼
Cloudflare Worker  insure-quest
   ├─ Static assets (Workers Static Assets): Godot export files in ../web
   ├─ /api/rooms…        Room creation, WebSocket ──▶ Room Durable Object (one per room; server-authoritative game logic, bot advisor)
   ├─ /api/auth/*        Google Login (OAuth, HttpOnly Cookie) ─┐
   ├─ /api/me /api/records /api/profile /api/learners ─────────┴▶ Records Durable Object (dual-track sharding: personal DO shard 10 GB stores detailed decisions and AI quota; global DO stores accounts and statistical summaries)
   └─ Workers AI (default, env.AI) / Claude (optional): AI clients, AI scoring, coach hints and feedback; 10 daily Workers AI requests per account (NVIDIA NIM is unlimited); fallback to rules-based engine when exceeded or for guests
```

- **Do not use Cloudflare Pages.** Pages cannot deploy Durable Objects. If Pages were used, an additional Worker would have to be deployed for DOs, resulting in two deployments and two domains (or service bindings). Workers Static Assets allows the web client and API / DO to be deployed together in a single Worker in one deployment, which is also Cloudflare's currently recommended approach for full-stack projects.
- **No need to split the repository.** The frontend (`client/`) and backend (`server/`) share game protocols; keeping them in the same monorepo is the safest for synchronized versioning, and deployment requires only a single command.
- **No need for an extra API domain.** The web app and `/api/*` are same-origin, eliminating CORS issues (cross-origin only occurs during desktop development, which the server already permits).

## Requirements

- (Optional) `pip install fonttools`: only needed when regenerating font subsets

## Local Development

```bash
cd server
npm install
npm run build:web     # Export Godot web build to ../web (compress wasm, fix PWA cache manifest, generate _headers)
npm run dev           # http://127.0.0.1:8787 (--env local: Workers AI requires prior npx wrangler login; set AI_PROVIDER=mock in .dev.vars for offline use)
npm run dev:remote-ai # Requires prior npx wrangler login; connects to real Workers AI
```

- Server-only code changes: `npm run dev` reloads automatically. When client changes, simply re-run `npm run build:web`; restarting the server is not necessary.
- Desktop version: Run `client/` directly using the Godot editor; the server address can be configured in the main menu (default `http://127.0.0.1:8787`).
- Local configuration: Copy `server/.dev.vars.example` to `.dev.vars` (test login, AI providers, Google credentials).
- Testing: `npm run check` (type checking + unit tests, including balance simulation).

## Deployment (Single Step)

```bash
cd server
npx wrangler login                          # First time
npx wrangler secret put GOOGLE_CLIENT_ID     # Google Login (optional; guest-only mode if unset)
npx wrangler secret put GOOGLE_CLIENT_SECRET
npx wrangler secret put NVIDIA_API_KEY        # Optional; prioritizes NVIDIA NIM (auto-fallback to Workers AI on failure/unconfigured)
npx wrangler secret put ANTHROPIC_API_KEY     # Optional; needed only when AI_PROVIDER=claude
npm run deploy                                # = build:web + wrangler deploy
```

Configuration is centralized in `server/wrangler.jsonc`: static asset directory, routing `/api/*` to the Worker first, Workers AI bindings, two Durable Object bindings and SQLite migrations (`v1`), AI / quota / trainer variables, and a `local` dev environment without AI bindings. Account data is stored in the existing Records Durable Object without requiring a separate D1 database; deployment remains a single step.

### Automated Deployment (GitHub Actions)

When pushed to `main`, `.github/workflows/deploy.yml` runs `npm run check` → downloads Godot and export templates → `npm run build:web` → `wrangler deploy`; PRs run checks only.
Configure Secrets in the GitHub repository: `CLOUDFLARE_API_TOKEN` (template "Edit Cloudflare Workers") and `CLOUDFLARE_ACCOUNT_ID`.
Connecting via Cloudflare Dashboard's "Connect to Git" (Workers Builds) is not recommended: its build image lacks Godot, requiring downloading Godot and ~1 GB export templates on every build to generate `web/`, whereas GitHub Actions can cache them.

When adding or renaming Durable Object classes, a new tag must be added in `migrations`; do not modify existing `v1`.

## Accounts, AI Quota, and Training Records

- **Dual-Track DO Sharding**:
  - **Personal DO Shard (`idFromName('user:' + userId)`)**: Each logged-in learner has a dedicated 10 GB SQLite storage space, preserving complete interview decision histories, detailed per-turn trajectories, and daily AI quotas. Personal data is strictly isolated, capacity is guaranteed not to overflow, and idle shards automatically hibernate without incurring maintenance costs.
  - **Global DO Instance (`idFromName('global')`)**: Stores account identities, login sessions, and lightweight match summaries. When trainers query the learner roster (`/api/learners`) or aggregated records (`/api/records?scope=all`), the global instance aggregates them quickly via a single SQL query, avoiding cross-shard fan-out latency and extra request billing.
- **Login**: Google OAuth authorization code flow is handled entirely within the Worker (`src/auth.ts`); sessions are stored in HttpOnly Cookies. Godot's HTTP and WebSocket automatically carry them over same-origin, keeping tokens hidden from the frontend. Cross-origin WebSockets do not inherit credentials.
- **AI Quota**: Calling NVIDIA NIM **is completely exempt from AI quota usage (unlimited)**; switching or falling back to Workers AI / Claude deducts 1 usage per call (`AI_DAILY_LIMIT`, default 10, resets midnight Taipei time; refunded on model failure). Guests, bot advisors, and users who exhaust their quota fall back to the rules-based engine, allowing the game to proceed normally.
- **AI Providers** (`AI_PROVIDER`): Prioritizes **NVIDIA NIM** (if `NVIDIA_API_KEY` is set; primary model `NVIDIA_MODEL`=nemotron-3-super; falls back on failure to NIM fallback model `NVIDIA_FALLBACK_MODEL`=deepseek-v4.1-flash [slower, 45s timeout; set `none` to disable]; on further failure falls back to **Workers AI**, model `WORKERS_AI_MODEL`=`@cf/qwen/qwen3.8-27b`) | `claude` (requires `ANTHROPIC_API_KEY`) | `mock` (local simulation) | `rules`.
- **Training records are saved only for logged-in users**, and users can only view their own; trainers in `TRAINER_EMAILS` can view all learners (`/api/records?scope=all`, `/api/learners`, `/api/profile?user=`).
- **What is saved**: In addition to scores, every interview stores a full decision trajectory (clues, questioning order, open-ended questions, configuration and review, objection responses, stress outcomes, whether hints were used) and tags weakness labels. The learning profile (`/api/profile`) aggregates these into: score and Five Powers trends, most frequent mistakes and improvement suggestions, client compendium (service count and best rating across 18 clients), and badges.

### Setting Up Google Login
1. Google Cloud Console → APIs & Services → Credentials → Create OAuth client ID (Web application).
2. Authorized redirect URIs: `https://<your-domain>/api/auth/google/callback` (add `http://localhost:8787/api/auth/google/callback` for local testing).
3. `npx wrangler secret put GOOGLE_CLIENT_ID`, `npx wrangler secret put GOOGLE_CLIENT_SECRET`; for local dev, configure in `server/.dev.vars`.
4. If not configured, the login button is automatically hidden and the game runs in guest mode. Locally, `DEV_LOGIN=1` can be set for test login (localhost only).

## Gameplay Enhancements (Comparison with Prototype)

| Item | Description |
|---|---|
| Scene Hotspots for Clues | Restored 3 clues + 1 distractor search on illustrations for the 5 illustrated clients from the prototype |
| Dedicated Endings vs. 「沒有規劃」(No Planning) Contrast | Interview results display Strong/Medium/Weak endings based on stress simulation, contrasting with the consequences of having no planning |
| Spectator Prediction | While another player is interviewing, other players predict the rating; guessing correctly grants +2 Prestige, eliminating downtime in multiplayer |
| Endgame Big Event | At the start of the final round, 「全球金融海嘯」(Global Financial Tsunami) tests all advisors' clients simultaneously |
| Coach Hint | Once per interview; deducts 2 Prestige; provides direction without giving away the answer |
| Illustrated Game Guide | Retains the prototype's 5 guide diagrams |

## Web Version Considerations

| Issue | Solution |
|---|---|
| Godot's `index.wasm` is ~38 MiB, exceeding the Worker single-file 25 MiB limit | `pack-web.mjs` compresses it to `index.wasm.gz` (~10 MiB) and injects a fetch shim into `index.html` to decompress in the browser |
| `wrangler dev` watcher aborts upon seeing uncompressed wasm in `web/` | `build-web.sh` exports to a temporary directory first, swapping into `web/` only after compression completes |
| Browser automatically decompresses gzip responses; Godot fails if decompressing again | In `net.gd`, set HTTPRequest `accept_gzip = false` |
| Godot web canvas cannot receive Chinese IME text | `web_text.gd` overlays a real HTML `<input>` over text fields |
| Font size is 12 MB | `subset-font.py` subsets the font to Big5 common characters + project vocabulary (~3 MB), preserving the variable weight axis |
| Font lacks emoji | UI uses only CJK characters and symbols like ✓ × ★ ● ◆ ※ |
| Images take up download bandwidth | Import settings changed to lossy WebP (quality 0.8), reducing pck from 14.7 MB to 3.2 MB |

## PWA

PWA is enabled during Godot export: generates manifest, icons, offline page, and service worker; supports 「加入主畫面」(Add to Home Screen) for fullscreen launch in portrait or landscape.
`pack-web.mjs` updates the service worker cache manifest to the actually downloaded `index.wasm.gz`; subsequent launches load the engine from cache.
An active server connection is required to play (multiplayer and AI run server-side); an offline page is shown when disconnected.
After deploying updates, installed users first load the cached previous version, and the main menu displays 「有新版本，點此更新」("New version available, click here to update"); the same applies during development (or check "Update on reload" in DevTools).
