# Round 4 請求（Claude → agy）：玩法、介面風格與美術審視

背景：Cardif InsurHack 1-1「保險大富翁－財務人生模擬遊戲」。Round 3 與 Batch 4–6 已完成（違規後果、十年財務曲線、體驗碼、新手教學、錄影工具），見 docs/design/round3-summary.md 與 docs/design/tasks/batch4~6。
目前畫面截圖：docs/design/round4-shots/frame-*.jpg（1280x720；1=載入/選單、8=選單、14/22=棋盤與面談、48=對話、56=方案、62=異議、80/86=結果頁）。請實際打開每張圖看。
程式：client/scripts/ui/*.gd（UI 全部程式碼生成，ui.gd 是元件與色票）、client/assets/（插畫）、server/src/game/*.ts（規則）。

請以「資深遊戲設計師 + 美術總監 + 評審」身分，用繁體中文條列回答，每點附工作量 S/M/L、影響的評分項、具體檔案：
1. 玩法：棋盤層目前還是「擲骰→觸發事件」，與面談/財務曲線的關聯弱。提出 3–5 個能讓「大富翁」本身有策略、又能強化「財務人生」與「售後服務/理賠」主題的機制（例如：簽約客戶在棋盤上留下標記、人生事件打到你的客戶簿觸發理賠服務、路線選擇、策略卡、整局以客戶十年結局計分）。指出哪些會破壞平衡或拖慢節奏。
2. 介面風格：目前像深藍色後台儀表板，不像遊戲。請提出一個明確的視覺方向（色票 hex、字級層級、圓角/陰影/描邊規則、按鈕狀態、面板材質、圖示風格），並說明與法巴人壽品牌（綠色系）如何呼應但不冒用其商標。比較 2 個方向後推薦 1 個。
3. 美術：主選單插畫（雨夜房間＋下跌K線，基調偏憂鬱）、棋盤格子（通用圖示）、棋子、客戶頭像（面談時很小）、場景插畫。哪些要重做、哪些可保留？可用 Workers AI flux 生成（server/tools/generate-all-scenes.mjs、/api/dev/gen-img），請給可直接使用的英文 prompt 與統一風格描述。
4. 回饋與動態（juice）：棋子移動、擲骰、簽約、紅燈、壓力測試、十年曲線出現時，該有哪些動畫/音效。
5. 依 ROI 排出 11/06 前要做的清單（≤ 8 項），以及延後清單。
不要修改任何檔案，只輸出分析。不要使用終端指令。
