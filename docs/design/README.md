## 診斷（雙方一致）
1. AI 只是點綴：一場面談只在 1 次自由提問＋1 次異議回應用到 AI，其餘都是選擇題。
2. 最佳解可以背：5 選 3、10 枚幣、卡片組合都是固定答案。
3. 棋盤與面談脫節；面談面板把棋盤整個遮住。
4. 配置錯了只會扣分，玩家感受不到後果。
